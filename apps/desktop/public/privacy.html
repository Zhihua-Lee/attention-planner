Attention Planner 隐私政策

Privacy Policy · 生效日期 / Effective: 2026-08-23

简要说明：任务和日历内容优先保存在你的设备。选择 Google Drive 同步时，任务 JSON 由浏览器直接写入 Google Drive 隐藏的 appDataFolder；Cloudflare OAuth/推送服务不接收任务标题、正文或日历内容。

我们处理的信息

  • 本地应用数据：任务、项目、设置和缓存保存在浏览器为 todo.onthat.top 隔离的本地存储中。
  • Google Drive 同步：经你授权后，PWA 仅使用 drive.appdata 权限访问本应用自己的隐藏文件，不能读取或修改普通 Drive 文件。短时访问令牌交给浏览器用于直连 Google Drive。
  • 长期授权：Google 刷新令牌先用应用密钥进行 AES-256-GCM 加密，再保存在仅允许指定 Google 账号登录的 Durable Object 中。
  • 后台推送：启用后保存浏览器推送端点、不可逆提醒 ID 和提醒时间。推送正文固定为通用提醒，不上传任务标题、描述、项目名或日历内容。
  • 身份与运行日志：Google 登录使用获准电子邮件识别唯一用户；会话保存在加密、HttpOnly、SameSite Cookie 中。Cloudflare、Google 及浏览器推送提供商可能按其服务规则处理 IP 地址、User-Agent、安全日志和必要的请求元数据。

用途、共享与出售

这些信息仅用于同步授权、安全访问、发送你主动启用的提醒、故障排查和防止滥用。必要信息会由 Cloudflare、Google 以及 Apple/浏览器推送服务处理。我们不出售个人信息，不投放行为广告，也不把任务数据用于训练模型。

保留、控制与删除

在「设置 → 同步」断开 Google Drive 会撤销授权并删除服务端刷新令牌；在「设置 → 通知」关闭此设备推送会删除该设备的推送端点和提醒计划。你也可以清除站点数据或删除 Google Drive 中的应用数据。Cloudflare 和 Google 的安全日志保留期由各自服务政策决定。

安全与限制

服务采用 HTTPS、Google PKCE 登录、单账号白名单、最小 Google 权限、令牌加密和通用推送内容。任何联网服务都不能承诺绝对安全；iOS 也可能因网络、省电或系统维护延迟推送。

开源、联系与变更

源代码按 AGPL-3.0 发布于 GitHub，上游为 Mindwtr。问题可通过 仓库 Issues 提交，请勿在公开 Issue 中粘贴令牌或私人任务内容。政策发生实质变更时会更新本页日期和源码历史。

Privacy Policy (English summary)

Attention Planner is local-first. When Google Drive sync is enabled, task JSON moves directly between the PWA and the app-specific hidden appDataFolder. The Cloudflare broker stores an application-encrypted Google refresh token. If Web Push is enabled, it stores only the push endpoint, opaque reminder IDs, and reminder times; notification text is generic. It does not receive task titles, descriptions, project names, or calendar content. Data is used only for authentication, sync authorization, user-requested reminders, security, and troubleshooting; it is not sold or used for advertising or model training. Disconnect Google Drive or disable device push in Settings to delete the corresponding server-side credentials and schedules.
