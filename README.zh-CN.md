# Attention Planner 注意力规划

**一张清单，告诉你现在做什么。**

这是一个不需要你“维护系统”的待办应用。你只负责把事情记下来；记住、排序交给它。任何时候打开，它都给出此刻最值得做的一件事，并说明为什么。没有要清空的收集箱，没有每周回顾，也没有要不停切换的状态。

[English](README.md) · [使用指南](docs/user-guide.md) · [设计](docs/design.md) · [开发](docs/development.md) · [验证记录](VERIFICATION.md)

## 能做什么

- **NOW**：只给一件事和一句理由（“现在是预留的时段 · 到 17:00”“今天截止”“标了重要”），附上截止、用时、步骤进度；下面是今天的日程，可以切到本周，也可以逐日翻看。
- **一张清单**：所有没做完的任务都在这里。筛选（今天、7 天内截止、有截止、新加的、暂缓、按区域或项目，可在设置里自选）只是收窄视图，改任何属性都不会让任务“跑到别处”。
- **一行记下**：输入 `周五交报告 3小时 !` 按回车即可。输入框下的标签显示识别出的内容，并按顺序提示下一步可补的信息：截止 → 哪天做 → 用时 → 重要。
- **安排**：一个任务可以排好几天，每天可以不定时间、选上午/下午/晚上，或从半小时一格的时间表里选具体时间（已有安排的时间显示为灰色），再选时长。
- **重复，两种方式**：**原地重开**（同一个任务每轮重新打开，步骤清空，往期记入历史）或**新建一份**（完成后生成下一次）。可以按日历，也可以从完成后计时；可以设结束日期，“新建一份”还能设总次数。每个步骤可以跟随任务、单独重复或不重复。
- **时间够不够**：填了用时，系统会比较每个截止前要做的总量和可用的空闲时间，不够时提醒你。
- **暂缓**取代了“等待中”“暂不做”和“最早”：任务留在清单里变灰，到你设的那天自动恢复。
- **搜索**标题、正文和步骤（`/` 或 `Ctrl+K`）；所有修改都能**撤销**（`Ctrl+Z`）。
- **离线可用**，可以装到 iPhone 主屏幕。数据保存在设备的 IndexedDB 里。
- **同步**通过 Google Drive，按字段合并，两台设备不会互相覆盖。
- **导入**旧应用导出的 JSON 和 `.ics` 日历文件。

界面有中文和英文，浅色和深色主题，尊重“减少动态效果”设置。

## 当前状态

0.1.1 已经在 todo.onthat.top 上取代旧应用。第一次打开时会自动导入浏览器里旧应用的数据；如果已经登录过，会自动通过同步中转连接 Google Drive 同步；Power Automate 导出到 Google Drive 的 Outlook 日历会显示在 NOW 里。推送提醒还没有做。具体验证了什么见 [VERIFICATION.md](VERIFICATION.md)。

## 运行

```bash
npm install
npm run dev
```

然后打开 http://localhost:5173。`npm run build`把 PWA 输出到`dist/`。详见 [docs/development.md](docs/development.md)。
