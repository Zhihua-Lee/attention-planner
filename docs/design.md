# 新数据模型（设计稿 v5）

**原则**：你只负责记下和做，记住和排序交给系统。只有一张主清单；任何操作都不会让任务“换地方”。

## 存什么

**任务 Task**

| 字段             | 含义                                                                                             |
| ---------------- | ------------------------------------------------------------------------------------------------ |
| 标题、正文、步骤 | 正文用 Markdown；步骤 = `{文字, 已勾}`。正文就是“怎么做”的资料：链接、要点、上次的经验都写在这里 |
| 归属             | 区域或项目，可空                                                                                 |
| 关联             | 指向另一个任务的指针，只影响列表里的排列                                                         |
| 完成于           | 唯一的“状态”；空 = 没做完                                                                        |
| 暂缓             | 开关，可选“到某天”和一句原因（如“等回信”）。只影响推荐，任务不挪位置                             |
| 截止             | 日期，可加时刻；唯一的时间限制                                                                   |
| 安排             | 列表，每条是“某天”或“某天 + 几点 + 多久”；时段可记录已做多少分钟                                 |
| 用时             | 总预计分钟数                                                                                     |
| 重要             | 一档星标；没有截止也该常冒出来的事                                                               |
| 重复             | 原地重开 / 新建一份 + 规则；步骤可以跟随任务、单独设规则或不重复                                 |

**区域 Area**、**项目 Project**：名称、顺序；项目可标记完成。

**不存的**：收集箱/待办/等待/将来/资料/归档、最早、情境、标签、精力、多级优先级。

## 系统算什么（不存）

- **NOW**：一件事 + 一句理由。只算“此刻”，不替你排未来的日程。依次看：正在进行的日历事件 → 当前时段 → 逾期或今天截止 → 今天的安排 → 标了重要的 → 其余没暂缓的任务（结合现在有多少空闲时间来挑）。
- **容量检查**：截止前需要的用时之和，对比截止前的空闲时间；不够就提醒（例如“周五前还差 2 小时”）。
- **今天**：安排里有今天的任务。
- **新加的**：最近 7 天记下、还没有安排也没有截止的任务。这是“未整理”的自动版，不需要手动整理。

## 界面

- 主菜单只有两个入口：**NOW**、**清单**；另有随处可用的“新建”，搜索和设置放在角落。日历只是 NOW 时间线里的一个视图（今天 / 本周）。
- **清单**：所有没做完的任务排成一列；顶部筛选：今天、新加的、有截止、暂缓、区域/项目。每行显示标题（★ 表示重要）、最近一次安排（还有更多时显示“+N”）、截止；暂缓的变灰，已完成的折叠在底部。
- **任务详情**：“安排”一行列出全部，可以分别增删。
- **NOW**：一件事 + 一句理由（例如“现在是预留的时段 · 周五截止”）；下面是今天的时间线。
- 每页一屏看完，不用滚动；不填任何属性也能用。

## 维度之间只有三条规则

1. 安排晚于截止：标红提醒。
2. 暂缓只影响推荐；已经排定的时段照常出现在日历上。
3. 新建时段的默认时长 = 剩余用时（总用时减去已做）。

## 同步

- 每条记录（任务、步骤、安排、区域、项目）带版本戳 `{版本号, 时间, 设备}`，按记录合并；删除留“墓碑”记录。
- Google Drive 上只存一个 JSON 文件，沿用现有的同步中转（OAuth、令牌、推送）。
- 本地改用 IndexedDB，不再用 localStorage（后者大约只有 5 MB 上限）。

## 旧数据怎么迁

| 旧                       | 新                                                                                                     |
| ------------------------ | ------------------------------------------------------------------------------------------------------ |
| 收集箱、待办             | 没做完                                                                                                 |
| 等待中、暂不做           | 暂缓（原因写成原状态名）                                                                               |
| 最早 10/5                | 暂缓到 10/5                                                                                            |
| 哪天想做、时段           | 安排                                                                                                   |
| 预计                     | 用时                                                                                                   |
| 重复、清单刷新           | 重复（新建一份 / 原地重开）                                                                            |
| 子任务指针               | 关联                                                                                                   |
| 归档                     | 完成                                                                                                   |
| 资料                     | 暂缓（原因写“资料”）。资料只用来帮你想起要做什么、怎么做，所以放在相关任务的正文里，不单独成为一类东西 |
| 优先级：高、紧急         | 重要                                                                                                   |
| 情境、标签、其余优先级等 | 原样存进隐藏的 `legacy` 字段，不显示，以后需要再说                                                     |
