# 使用指南

## 两个入口

- **NOW**：现在做什么。打开应用默认在这里。
- **清单**：所有没做完的任务。

右上角依次是：撤销、搜索、全宽（大屏阅读用，只记在这台设备上；全宽时 NOW 的日程拉满到屏幕底部）、设置。

## 记下一件事

在清单页顶部的输入框里写，按回车就保存。什么都不用填。

输入时可以顺手写上信息，系统会识别出来，显示成下面的标签：

| 写法                                                                                                    | 识别为                                                                        |
| ------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| `周五交报告`、`截止明天`、`report due fri`                                                              | 截止                                                                          |
| `明天下午`、`后天晚上8点`、`下周一 3点半`、`tomorrow at 7pm`                                            | 哪天做（可带上午/下午/晚上或具体时间）                                        |
| `10月20日`、`10/20`、`2027-01-05`、`30号`、`月底`、`下个月初`、`Oct 20`                                 | 具体日期（没写年份就是下一个这天；只写几号就是本月的，过了就是下个月的）      |
| `3小时`、`30分钟`、`2h`、`45m`                                                                          | 用时                                                                          |
| 单独的 `!`                                                                                              | 重要 ★                                                                        |
| `每天`、`每3天`、`每个工作日`、`每周一三五`、`每两周`、`每月15号`、`每年`、`daily`、`every mon and thu` | 重复：带截止的（如 `每周五交周报`，截止下一个周五）每次新建一份，否则原地重开 |

识别错了，点一下那个标签就撤掉。没写的信息，也可以点标签补：标签按“对系统有多大用”排序（截止 → 哪天做 → 用时 → ★），“＋更多”里有归属、重复和正文。填了截止却没填用时，“用时”标签会亮一个小点提醒——有了用时才能检查时间够不够。

标签的顺序和哪些放前排，可以在设置里改。

## 不打开应用也能记

- **网址**：`todo.onthat.top/?add=周五交报告` 打开就记下这一句（规则和输入框一样）。可以存成书签，或者给启动器、脚本用。
- **安卓**：在任何应用里选中文字 → 分享 → Attention Planner。
- **iPhone 快捷指令 / Siri**：设置 → 记录与清单 → 快捷记录 → 生成专属链接，按里面的步骤做一个“记一下”快捷指令，之后对 Siri 说“记一下”就行，不用打开应用。专属链接只能新增任务、不能读取；生成新链接或停用后旧的立即失效。需要先连接同步。

## NOW

卡片上只有一件事：

- **理由**：为什么是它。顺序是：正在进行的预留时段 → 你打算“现在这个时段”做的（上午/下午/晚上） → 已经过了截止 → 今天截止 → 今天想做 → 标了重要 → 最早记下的。
- **事实**：截止、用时（还剩多少）、步骤进度、重复规则；有步骤时显示“下一步”。
- **完成** / **换一件** / **打开**。右下角是“下一件”。

正在上课或开会（日历里有事件）时，卡片显示这个事件。

卡片下面：

- 如果某个截止前时间不够，会出现一行提醒：“交报告：周五前大约还差 2 小时”。
- **日程**：上方一排是全天事件、截止和没定具体时间的安排；下面是 24 小时的时间轴，可以上下滚动，打开时自动停在现在，红线和时间标出此刻。同时发生的日程并排显示；块的高度对应时长（每小时固定高度，方便一眼看完一天）。点任何一项会弹出详情（时间、时长、地点、用时、步骤），预留的时段可以直接“改时间”或“删除”。右键一个预留的时段，菜单里有完成任务、改时间、打开任务和取消这次预留；右键日历事件，菜单顶上写着它的时间和来处（Outlook、订阅的日历或导入的文件，要在那边修改），可以看详情，还没结束的可以从它结束时起预留时段；右键全天事件、截止或没定时间的安排，可以完成或打开任务；右键空白时间和点一下一样。点空白时间可以预留：选新任务或已有任务，调整开始时间和时长，和别的安排重叠时会提醒。上面会先列出最适合这段时间的几件任务（截止最近的在前，其次是放得下的、重要的），点一下就选中；不想要可以在设置 → 日历里关掉“点空白时间时推荐任务”。用“今天 ‹ ›”逐日翻，“日 / 周”切换；周视图里点某一天会跳到那天；周视图里的每一项也能右键，菜单和日视图一样，右键某一天的空处可以跳到那天或在那天预留。

## 清单与任务详情

点任务标题，详情在原地展开；标题本身就可以直接改。在设置 → 记录与清单 → 任务行的操作里选“右键菜单”的话，行上不再显示 ☀，在一行上点右键（手机上长按）弹出菜单：完成、加到今天、截止、安排、找时间、重要、暂缓、区域、上级任务、打开、删除；需要再选的（截止、安排……）会在这一行旁边弹出选择。菜单里用 ↑↓ 移动、回车选、Esc 关上。点这个任务以外的地方、点它顶部那一行的空白处、按 Esc 或点“收起”，详情就收起（菜单开着时，第一下只关菜单）。所有修改立即保存。

- **截止**：日期，可加时刻。
- **安排**：点“+ 添加”，先选哪天，再选什么时候——不定、上午、下午、晚上，或从半小时一格的时间表里点开始时间（灰色表示和已有日程或别的时段重叠），再点时长。默认时长取剩余用时（最多 2 小时）。一个任务可以有好几条安排；点一条可以改时间或删除。
- **用时**：总共要花多久。下面显示已排、已做。
- **找时间**：用时旁边的“找时间”按还差的时长（用时减去已排的；没填用时按 1 小时）在截止前（没截止就是两周内）的工作时间里找空档，避开日程和别的预留，每段最多 2 小时，放不下就先给短一点的一段。点一下就预留。预留多少都不会改用时；没填用时时可以顺手把用时记成 1 小时。
- **步骤**：长的步骤会自动换行，Shift+回车在步骤里换行；回车添加。添加时也认快捷写法：日期是这一步的截止（`周五 交初稿`），时长是它的用时（`30分钟`），`每天`、`每周一` 让它单独重复，`不重复` 让它在原地重开的任务里不清空；识别出的内容显示在框下面，点一下就撤掉、文字留在步骤里。拖动左边的 ⠿ 调整顺序（键盘上在 ⠿ 上按 ↑↓）；× 删除。每一步可以有自己的截止（最早的未完成截止会显示在清单和 NOW 里，比如“步骤“画图”今天截止”）、自己的用时（任务没填总用时时，按步骤相加，剩余只算没做完的）、自己的重复（跟随任务、不重复，或者单独按一套规则重复），也可以“独立成任务”（变成关联到这里的新任务，带走截止、用时和给它的安排）。**☀ 今天做这一步**：整个任务进入“今天”，NOW 的“下一步”先给这一步，步骤后面显示“☀ 今天”（点一下移出），第二天自然失效。**给这一步找时间**：点用时，在弹出框里按这一步的用时（没填按 1 小时）、在它的截止前找空档，点一下就在日历上预留，日程里显示成“这一步 · 任务”。步骤后面显示哪些按钮在设置里选；电脑上鼠标移到步骤上才出现，手机上点一下某个步骤才出现。
- **重复**：见下一节。
- **其他**：★ 重要；暂缓（可以设“暂缓到哪天”和原因，比如“等回信”）。
- **区域**：长期存在、永远做不完的一块（科研、教学、家务），可以直接新建。子任务没设区域时，算在上级任务的区域里（显示“随上级任务”）。
- **上级任务**：把这个任务放到另一个任务下面，成为它的子任务；子任务还可以有自己的子任务。清单里子任务排在上级下面，每深一层多缩进一点（三层以后不再加），用竖线标出；上级没显示时，行里写“→ 上级的名字”。任务详情里也会列出它的子任务。不能放到自己或自己的子任务下面。它只影响排列：上级完成了，子任务照旧。
- **正文**：点一下就能写，支持 Markdown。适合记“怎么做”：链接、要点、上次的经验。写进去的本地完整路径会变成链接，见下面的“本地路径”。
- **历史**：正文下面，点开看这个任务做过什么，按天排列、最新的在前：勾选或取消勾选哪一步、完成、重新打开、改截止、安排和改期、记下做了多久、暂缓。勾选和完成会记下当时的情况，比如“原定晚上”“截止 10/2”；经 AI 提议批准的会写明是哪个 AI。撤销会把刚记的那条一起撤掉。各台设备的历史合在一起，每个任务保留最近 200 条。连接的 AI 也能读到它，用来了解你实际什么时候、花多久做这类事。

勾掉左边的圆圈就是完成；完成的任务折叠在清单底部的“已完成”里。完成、删除、记下都可以在底部提示里撤销，也可以按 `Ctrl+Z`。

清单上方的筛选：全部、今天（今天截止或已逾期的，包括步骤的截止；今天有安排的；重复任务还没完成的这一轮——每天重复的会一直在，直到做完；单独重复的步骤到了这一轮），以及有内容时才出现的：7 天内截止、有截止（所有带截止的）、重要（标了 ★ 的）、新加的（最近 7 天记下、还没给日期、截止、重复或归属）、未安排（没截止、没安排、不重复、没暂缓的）、暂缓、各个区域。“今天”旁边的 ⓘ 会说明它包括什么。

**加到今天**（像“我的一天”）：电脑上鼠标移到一行，点右边的 ☀，或者选中那一行按 `T`；手机上把那一行往左滑；任务详情的“安排”里也有“☀ 加到今天”。它就是给任务加一条今天的安排；再点一次（或再滑一次）就移出。第二天它自然离开“今天”，不算逾期。打开“今天”筛选时，如果昨天计划的还有没做完的，顶部会提示“昨天计划了 N 件还没做”，点“都加到今天”才会挪过来，不会自动挪。显示哪些筛选可以在设置 → 清单筛选里勾选。右边可以切换排序：智能（暂缓的在后，重要的在前，再按截止和新旧）或手动（拖动每行左边的 ⠿，或在 ⠿ 上按 ↑↓；新任务在最上面）。

## 重复

在任务详情里点“重复”：

- **不重复**
- **原地重开**：同一个任务每轮重新打开，步骤清空，每轮的完成记在任务的“历史”里。点圆圈完成这一轮（设置里打开“步骤都勾完时 · 自动完成任务”后，勾完所有步骤就自动完成）；这一轮做完后任务仍留在清单里，显示“下一轮 …”。适合每周固定要过一遍的清单。
- **新建一份**：完成时这一个归档，同时按规则生成下一次，截止和安排一起顺延，步骤重置。任务有截止时，可以设“提前出现：截止前 N 天”：下一份先暂缓，到截止前 N 天才回到清单和 NOW（比如每周五交周报、提前 2 天，就是周三出现）。不设就是完成后马上出现。

规则：频率（按天/周/月/年；原地重开且从完成后计时时还有按小时）、每隔几个单位、是否“从完成后计时”、星期或每月哪天、何时停止（不设、到指定日期；“新建一份”还可以设总次数）。“更多”里有开始日期，原地重开还有刷新时刻和暂停。

原地重开的任务里，每个步骤旁的 ↻ 可以设：跟随任务、不重复、单独每天、单独每周。

## 搜索

按 `/` 或 `Ctrl+K`，或点右上角的放大镜。搜标题、正文和步骤，匹配的文字高亮；↑↓ 选择，回车打开。

## 设置

设置分成六组：常用、记录与清单、提醒、日历、同步与数据、AI 连接。电脑上分组在左边，手机上在顶部一排；点一组就跳过去，滚动时会自动标出当前所在的组。每一项标题旁的 ⓘ 用白话解释它做什么，点一下打开，点别处或按 `Esc` 关上。

**常用**

- **目标**：写下你最长远的方向，AI 排计划、拆任务时会参考；可以选“在 NOW 顶部显示”。见下面的“目标”。
- **外观与语言**：跟随系统 / 浅色 / 深色；中文 / English。
- **可用于做事的时间**：你一般在哪几天、几点到几点做事。“找时间”和日历空白处的推荐只在这段时间里找；判断“截止前时间够不够”也只算这段时间。

**记录与清单**

- **记录时的标签**：输入框下面那排小按钮（截止、哪天做、用时……）。排在前面的直接显示，按这里的顺序；其余收在“更多”里。用 ↑↓ 调顺序，− 收进“更多”，＋ 放回前排。
- **快捷记录**：不打开应用也能记，见上面的“不打开应用也能记”。
- **步骤都勾完时**：勾上“自动完成任务”，任务的步骤全部勾完就自动完成（原地重开的是完成这一轮）；默认不勾，等你自己点完成。无论勾不勾，取消勾选一步会让已完成的任务回到未完成；按自己节奏重复的步骤又到时间时，已完成的任务也会回到清单，勾掉这一步就又算完成。
- **打开任务时**：勾上“跳到第一个没勾的步骤”，打开任务时页面会直接跳过前面已勾掉的步骤，停在第一个没勾的步骤上（默认不勾）。
- **任务行的操作**：“按钮”（行上的 ☀）或“右键菜单”（右键或长按一行弹出全部操作），二选一。
- **步骤的操作**：“按钮”或“右键菜单”，二选一。选“按钮”时，勾选每个步骤后面显示哪些小按钮（今日、截止、用时与找时间、重复、独立成任务）；选“右键菜单”时步骤后面不放按钮，右键或长按步骤弹出这些操作和删除。电脑上鼠标移到步骤上才出现。拖动排序和删除一直都有；已经设好的今天、截止、用时、重复，不勾也会以小标签显示。
- **清单筛选**：清单上方显示哪些筛选按钮。“全部”一直都在；暂时没有任务的筛选会自动隐藏。
- **区域**：长期存在、没有终点的一块（科研、教学、家务）。可以改名、新建、删除（删除不会删掉里面的任务）。做完就结束的一件大事（投一篇论文）不需要单独的东西：它就是一个任务，各部分放到它下面当子任务。

**提醒**

- **这台设备的通知**：开启后，截止当天、预留时段开始前、AI 有新提议时会弹通知，应用关着也能收到。可以设截止当天几点提醒、预留时段提前几分钟。要先连接同步；每台设备分别开启。详见下面的“提醒”。

**日历**

- **点空白时间时推荐任务**：在日程里点空白时间预留时，先列出最适合这段时间的几件任务。默认开。
- **Outlook 日历**：Outlook 里的日程由 Power Automate 定时导出到你的 Google Drive（`outlook-calendar.json`），连上同步后应用自动读取，最多 10 分钟更新一次，也可以点“刷新”。只读，不会改你的 Outlook。第一次用时点开“怎么设置 Outlook”：应用会在你的 Drive 里准备好这个文件，并列出 Power Automate 的步骤；完整步骤见 [Outlook 设置](outlook-setup.md)。
- **订阅日历**：粘贴日历的订阅链接（以 `.ics` 结尾或 `webcal://` 开头的网址，比如课表、节假日），每 30 分钟自动更新；订阅会同步到所有设备。
- **日历文件**：导入一个 `.ics` 日历文件（日历应用“导出”得到的）。只存在这台设备上，不同步，也不会自动更新。

**同步与数据**

- **同步**：点“连接”，登录 Google，任务就会在你的各台设备之间同步。数据存在你自己 Google Drive 里一个隐藏的应用文件夹，别人看不到，Drive 网页上也看不到；应用只能读写它自己建的文件。连上后有“立即同步”和“断开”。“高级：同步服务地址”一般不用改，只有自己部署了同步服务（见 [sync-setup.md](sync-setup.md)）才填。
- **数据**：“导出备份”把全部任务、区域和设置存成一个 `.json` 文件；“导入旧应用数据”把以前那版导出的文件搬进来（可以撤销），见下面的“从旧应用迁移”。

**AI 连接**

- **连接地址**：在 ChatGPT、Claude 等 AI 应用里“添加连接器 / MCP 服务器”，填这个地址，登录 Google 后点“允许”。“管理”里能看到、断开已连接的 AI。
- **AI 新建任务无需批准**：默认不勾，AI 新建的任务也要你批准；勾上后直接保存。修改、完成、删除已有任务一定要你批准。详见下面的“AI 连接”。

## 提醒

设置 → 提醒 → 开启提醒（需要先连接同步）。之后在这台设备上：截止当天的指定时间（默认 9:00；有具体时刻的截止提前 1 小时）、步骤截止当天、预留时段开始前（默认 5 分钟）会弹通知，应用没打开也能收到，点通知直接打开那个任务。iPhone 需要先把应用添加到主屏幕（iOS 16.4 及以上）。推送服务只知道一个编号和时间，通知里的任务名是在你的设备上填进去的。

## 两台设备同时改了同一段文字

如果手机和电脑在都没看到对方修改的情况下，改了同一个任务的标题或正文，同步后会显示较晚的一版，另一版保留下来：任务详情里会出现提示，可以“保留这一版”“换成另一版”或“对照两版”；清单那一行会标“有两个版本”。先后修改（一台改完同步了，另一台再改）不算冲突。

## 只看下一个

清单里有子任务时，筛选旁边会出现“只看下一个”。打开后，每个上级任务下面只显示一个子任务——按清单当前的排序排在最前、还没做完的那个——其余的收起来，上级那一行写“还有 N 个子任务”。它只改变显示，不影响 NOW 和提醒；再点一下就全部显示。

## 按区域分组

“全部”里，筛选条后面的“按区域分组”把清单按区域分成几段（按区域的顺序，没有区域的放最后），每段里还是原来的排序；子任务跟着上级任务的区域走。区域名竖着写在这一段任务的左边；点它可以把这一段收成一行，折叠在这台设备上记住。它只改变显示：平时的一整列里最急的在最上面，分组后别的区域里急的事可能排在下面，所以需要时再打开。

0.2.39 起没有“项目”了：以前的项目自动变成一个同名的上级任务（在原来的区域里），里面的任务成为它的子任务；“按顺序”也去掉了，需要时用“只看下一个”。

## 目标

设置 → 目标：用自己的话写下最长远的方向（支持 Markdown）。它不计进度、不催你；AI 问“现在做什么”时会读到它，排优先级、拆任务、写提议时都会参照，提议和目标明显无关时会提醒你。想在 NOW 顶部看到它，勾上“在 NOW 顶部显示”（默认关）：只显示第一行，点一下看全文。

## 本地路径

正文里写完整路径，比如 E:\笔记\计划.md，它会变成链接。有空格的路径放在反引号里：`E:\my notes\计划.md`；也可以写成 [计划](E:/笔记/计划.md)。

在设置 → 记录与清单 → 本地路径里添加你常用的文件夹，写上放的是什么（比如“论文和数据”）。列表会同步；连接的 AI 会读到它，写任务时把要用的文件夹和文件写进正文。

浏览器自己打不开本地文件，所以默认点一下是复制路径。在 Windows 电脑上装一个小程序后，点一下就直接打开：文件夹在资源管理器里打开，.md、.txt、.pdf 和图片用默认程序打开（把 .md 的默认程序设成 Marklore，就在 Marklore 里打开）。它只打开安装时允许的文件夹里的东西，不打开程序、脚本和快捷方式。

1. 下载本仓库（只要 `tools/open-link` 文件夹也行），放在你想放的地方，小程序就从那里运行。
2. 在设置的本地路径里点“复制安装命令”，它已经填好了你列的文件夹。在 PowerShell 里进入 `tools\open-link` 文件夹，粘贴运行。命令的样子：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install.ps1 -Roots "E:\研究;E:\笔记"
   ```

3. 设置 → 记录与清单 → 本地路径，勾上“这台设备点路径直接打开”。
4. 第一次点路径时，浏览器会问要不要打开 Windows Based Script Host，勾上总是允许 todo.onthat.top 打开这类链接。

它只为当前 Windows 用户注册 `ap-open:` 链接，不需要管理员权限。改了文件夹列表，再复制一次安装命令运行；卸载运行同一文件夹里的 `uninstall.ps1`。手机和没装小程序的电脑上，点路径还是复制。

## AI 连接

设置 → AI 连接里有连接地址，在 ChatGPT、Claude 等 AI 应用里添加它，按页面提示登录、允许即可。AI 可以查看清单、回答“现在做什么”；要新建或修改任务时，会先变成“提议”出现在清单顶部的“AI 提议”里，被改到的任务也会标出来。提议按批准后的样子画出来：新任务和新步骤是虚线框，要删的划掉，改动的地方高亮、旧值划掉放在旁边；有变化的行整行染色，末尾写明“勾选”“修改”“移动”“完成”等，没变的步骤变淡；“明细”里有逐条文字。批准后才生效（可以撤销），AI 也可以撤回自己还没被处理的提议。详见 [AI 连接](ai-connections.md)。

## 快捷键

| 键                      | 作用                                         |
| ----------------------- | -------------------------------------------- |
| `N`                     | 记下新任务                                   |
| `/`、`Ctrl+K`、`Ctrl+F` | 搜索                                         |
| `Ctrl+S`                | 立即同步（平时自动保存，不会弹出“保存网页”） |
| `Ctrl+Z`                | 撤销（在空的输入框里也行）                   |
| `Esc`                   | 关闭弹出层、收起详情                         |

打印、打开文件、查看源代码、加书签这些针对网页的快捷键（`Ctrl+P/O/U/D/G`）在应用里不起作用。右键也不弹浏览器的菜单，只有在输入框里、链接上和选中的文字上照常弹（方便复制粘贴、在新标签页打开）；手机上长按不受影响。任务行、步骤（设置里选了“右键菜单”时）和 NOW 的日程（日视图和周视图）上，右键是应用自己的菜单。

## 从旧应用迁移

在 todo.onthat.top 上第一次打开新应用时，会自动导入这个浏览器里旧应用的数据（只导入一次，可以撤销）。每台设备各自导入一次，记录保留原来的 ID，同步后会合并、不会重复；已经有的任务不会被导入覆盖，导入的内容也比任何一次真实修改都“旧”，所以在新设备上导入不会把别处的新改动改回去。也可以在旧应用里导出 JSON，再到设置 → 数据 → 导入旧应用数据。对应关系：

| 旧                     | 新                     |
| ---------------------- | ---------------------- |
| 收集箱、待办           | 没做完                 |
| 等待中、暂不做、资料   | 暂缓（原因写原状态名） |
| 可以开始（最早）在未来 | 暂缓到那天             |
| 哪天想做、时段         | 安排                   |
| 预计                   | 用时                   |
| 优先级“高”“紧急”       | 重要                   |
| 清单刷新 / 重复        | 原地重开 / 新建一份    |
| 子任务指针             | 上级任务               |
| 已完成、归档           | 已完成                 |
| 情境、标签、其余优先级 | 原样保存，暂不显示     |

导入后可以撤销。原地重开的任务从新的一轮开始（旧的每轮勾选记录不带过来）；单独计时的步骤（比如“完成后 2 周”）如果在旧应用里已经勾了，会按当时的完成时间带过来。
