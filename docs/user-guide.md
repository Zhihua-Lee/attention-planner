# 使用指南

## 两个入口

- **NOW**：现在做什么。打开应用默认在这里。
- **清单**：所有没做完的任务。

右上角依次是：撤销、搜索、全宽（大屏阅读用，只记在这台设备上）、设置。

## 记下一件事

在清单页顶部的输入框里写，按回车就保存。什么都不用填。

输入时可以顺手写上信息，系统会识别出来，显示成下面的标签：

| 写法                                                                                                    | 识别为                                                                        |
| ------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| `周五交报告`、`截止明天`、`report due fri`                                                              | 截止                                                                          |
| `明天下午`、`后天晚上8点`、`下周一 3点半`、`tomorrow at 7pm`                                            | 哪天做（可带上午/下午/晚上或具体时间）                                        |
| `3小时`、`30分钟`、`2h`、`45m`                                                                          | 用时                                                                          |
| 单独的 `!`                                                                                              | 重要 ★                                                                        |
| `每天`、`每3天`、`每个工作日`、`每周一三五`、`每两周`、`每月15号`、`每年`、`daily`、`every mon and thu` | 重复：带截止的（如 `每周五交周报`，截止下一个周五）每次新建一份，否则原地重开 |

识别错了，点一下那个标签就撤掉。没写的信息，也可以点标签补：标签按“对系统有多大用”排序（截止 → 哪天做 → 用时 → ★），“＋更多”里有归属、重复和正文。填了截止却没填用时，“用时”标签会亮一个小点提醒——有了用时才能检查时间够不够。

标签的顺序和哪些放前排，可以在设置里改。

## NOW

卡片上只有一件事：

- **理由**：为什么是它。顺序是：正在进行的预留时段 → 你打算“现在这个时段”做的（上午/下午/晚上） → 已经过了截止 → 今天截止 → 今天想做 → 标了重要 → 最早记下的。
- **事实**：截止、用时（还剩多少）、步骤进度、重复规则；有步骤时显示“下一步”。
- **完成** / **换一件** / **打开**。右下角是“下一件”。

正在上课或开会（日历里有事件）时，卡片显示这个事件。

卡片下面：

- 如果某个截止前时间不够，会出现一行提醒：“交报告：周五前大约还差 2 小时”。
- **日程**：上方一排是全天事件、截止和没定具体时间的安排；下面是 24 小时的时间轴，可以上下滚动，打开时自动停在现在，红线和时间标出此刻。同时发生的日程并排显示；块的高度对应时长（每小时固定高度，方便一眼看完一天）。点任何一项会弹出详情（时间、时长、地点、用时、步骤），预留的时段可以直接“改时间”或“删除”。点空白时间可以预留：选新任务或已有任务，调整开始时间和时长，和别的安排重叠时会提醒。上面会先列出最适合这段时间的几件任务（截止最近的在前，其次是放得下的、重要的），点一下就选中；不想要可以在设置 → 日历里关掉“点空白时间时推荐任务”。用“今天 ‹ ›”逐日翻，“日 / 周”切换；周视图里点某一天会跳到那天。

## 清单与任务详情

点任务标题，详情在原地展开；标题本身就可以直接改。所有修改立即保存。

- **截止**：日期，可加时刻。
- **安排**：点“+ 添加”，先选哪天，再选什么时候——不定、上午、下午、晚上，或从半小时一格的时间表里点开始时间（灰色表示和已有日程或别的时段重叠），再点时长。默认时长取剩余用时（最多 2 小时）。一个任务可以有好几条安排；点一条可以改时间或删除。
- **用时**：总共要花多久。下面显示已排、已做。
- **找时间**：用时旁边的“找时间”按还差的时长（用时减去已排的；没填用时按 1 小时）在截止前（没截止就是两周内）的工作时间里找空档，避开日程和别的预留，每段最多 2 小时，放不下就先给短一点的一段。点一下就预留。预留多少都不会改用时；没填用时时可以顺手把用时记成 1 小时。
- **步骤**：长的步骤会自动换行，Shift+回车在步骤里换行；回车添加。添加时也认快捷写法：日期是这一步的截止（`周五 交初稿`），时长是它的用时（`30分钟`），`每天`、`每周一` 让它单独重复，`不重复` 让它在原地重开的任务里不清空；识别出的内容显示在框下面，点一下就撤掉、文字留在步骤里。拖动左边的 ⠿ 调整顺序（键盘上在 ⠿ 上按 ↑↓）；× 删除。每一步可以有自己的截止（最早的未完成截止会显示在清单和 NOW 里，比如“步骤“画图”今天截止”）、自己的用时（任务没填总用时时，按步骤相加，剩余只算没做完的）、自己的重复（跟随任务、不重复，或者单独按一套规则重复），也可以“独立成任务”（变成关联到这里的新任务，带走截止和用时）。步骤后面显示哪些按钮在设置里选；手机上点一下某个步骤才会出现它的按钮。
- **重复**：见下一节。
- **其他**：★ 重要；暂缓（可以设“暂缓到哪天”和原因，比如“等回信”）。
- **归属**：区域或项目，可以直接新建。
- **关联**：指向另一个任务。关联的任务在清单里紧跟在它后面，用一条竖线标出。
- **正文**：点一下就能写，支持 Markdown。适合记“怎么做”：链接、要点、上次的经验。

勾掉左边的圆圈就是完成；完成的任务折叠在清单底部的“已完成”里。完成、删除、记下都可以在底部提示里撤销，也可以按 `Ctrl+Z`。

清单上方的筛选：全部、今天（今天截止或已逾期的，包括步骤的截止；今天有安排的；重复任务还没完成的这一轮——每天重复的会一直在，直到做完；单独重复的步骤到了这一轮），以及有内容时才出现的：7 天内截止、有截止（所有带截止的）、新加的（最近 7 天记下、还没给日期、截止、重复或归属）、暂缓、各个区域和项目。显示哪些筛选可以在设置 → 清单筛选里勾选。右边可以切换排序：智能（暂缓的在后，重要的在前，再按截止和新旧）或手动（拖动每行左边的 ⠿，或在 ⠿ 上按 ↑↓；新任务在最上面）。

## 重复

在任务详情里点“重复”：

- **不重复**
- **原地重开**：同一个任务每轮重新打开，步骤清空，往期记入“完成历史”。勾完所有步骤，这一轮就自动完成；这一轮做完后任务仍留在清单里，显示“下一轮 …”。适合每周固定要过一遍的清单。
- **新建一份**：完成时这一个归档，同时按规则生成下一次，截止和安排一起顺延，步骤重置。

规则：频率（按天/周/月/年；原地重开且从完成后计时时还有按小时）、每隔几个单位、是否“从完成后计时”、星期或每月哪天、何时停止（不设、到指定日期；“新建一份”还可以设总次数）。“更多”里有开始日期，原地重开还有刷新时刻和暂停。

原地重开的任务里，每个步骤旁的 ↻ 可以设：跟随任务、不重复、单独每天、单独每周。

## 搜索

按 `/` 或 `Ctrl+K`，或点右上角的放大镜。搜标题、正文和步骤，匹配的文字高亮；↑↓ 选择，回车打开。

## 设置

- 外观（跟随系统/浅色/深色）和语言（中文/English）。
- 可用于做事的时间：哪几天、几点到几点。用来计算空闲时间和“时间够不够”。
- 记录时的标签：前排的顺序，以及哪些收进“更多”。
- 区域与项目：改名、删除、新建。
- 日历：连上同步后，会自动读取 Power Automate 导出到 Google Drive 的 Outlook 日历（每次同步后更新，最多 10 分钟一次，也可以点“刷新”）；也可以按网址订阅其他日历（.ics 或 webcal 链接，比如课表、节假日），每 30 分钟自动更新；还可以导入 `.ics` 文件（只存在这台设备上）。
- 数据：导入旧应用导出的 JSON；导出备份。
- 同步：填同步中转地址后连接 Google Drive。

## 提醒

设置 → 提醒 → 开启提醒（需要先连接同步）。之后在这台设备上：截止当天的指定时间（默认 9:00；有具体时刻的截止提前 1 小时）、步骤截止当天、预留时段开始前（默认 5 分钟）会弹通知，应用没打开也能收到，点通知直接打开那个任务。iPhone 需要先把应用添加到主屏幕（iOS 16.4 及以上）。推送服务只知道一个编号和时间，通知里的任务名是在你的设备上填进去的。

## 两台设备同时改了同一段文字

如果手机和电脑在都没看到对方修改的情况下，改了同一个任务的标题或正文，同步后会显示较晚的一版，另一版保留下来：任务详情里会出现提示，可以“保留这一版”“换成另一版”或“对照两版”；清单那一行会标“有两个版本”。先后修改（一台改完同步了，另一台再改）不算冲突。

## 按顺序的项目

设置 → 区域与项目，给项目勾上“按顺序”。项目里的任务按添加的先后排队：前面的没做完，后面的显示“排队中”，NOW 也不会推荐它们。

## AI 连接

设置 → AI 连接里有 MCP 地址，在 ChatGPT、Claude 等 AI 客户端里添加它，按页面提示允许即可。AI 可以查看清单、回答“现在做什么”、直接记下新任务；要修改已有任务时，提议会出现在清单顶部的“AI 提议”里，被改到的任务也会标出来，点开就能看到改前 → 改后，批准后才生效（可以撤销）。详见 [AI 连接](ai-connections.md)。

## 快捷键

| 键                      | 作用                                         |
| ----------------------- | -------------------------------------------- |
| `N`                     | 记下新任务                                   |
| `/`、`Ctrl+K`、`Ctrl+F` | 搜索                                         |
| `Ctrl+S`                | 立即同步（平时自动保存，不会弹出“保存网页”） |
| `Ctrl+Z`                | 撤销（在空的输入框里也行）                   |
| `Esc`                   | 关闭弹出层、收起详情                         |

打印、打开文件、查看源代码、加书签这些针对网页的快捷键（`Ctrl+P/O/U/D/G`）在应用里不起作用。

## 从旧应用迁移

在 todo.onthat.top 上第一次打开新应用时，会自动导入这个浏览器里旧应用的数据（只导入一次，可以撤销）。每台设备各自导入一次，记录保留原来的 ID，同步后会合并、不会重复。也可以在旧应用里导出 JSON，再到设置 → 数据 → 导入旧应用数据。对应关系：

| 旧                     | 新                     |
| ---------------------- | ---------------------- |
| 收集箱、待办           | 没做完                 |
| 等待中、暂不做、资料   | 暂缓（原因写原状态名） |
| 可以开始（最早）在未来 | 暂缓到那天             |
| 哪天想做、时段         | 安排                   |
| 预计                   | 用时                   |
| 优先级“高”“紧急”       | 重要                   |
| 清单刷新 / 重复        | 原地重开 / 新建一份    |
| 子任务指针             | 关联                   |
| 已完成、归档           | 已完成                 |
| 情境、标签、其余优先级 | 原样保存，暂不显示     |

导入后可以撤销。原地重开的任务从新的一轮开始（旧的每轮勾选记录不带过来）。
