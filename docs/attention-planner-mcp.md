# Attention Planner 远程 MCP：AI 读取、草稿与确认修改

状态：**代码已实现，默认关闭；本次尚未部署，也未完成真实 ChatGPT、Codex 与 Google Drive 条件写入联调。** 本文的连接步骤用于部署验收，不代表线上已经可用。

## 这是什么

你仍然只有一份 Attention Planner 数据。MCP 是让 AI 聊天客户端操作这份数据的接口，不是另一套 Todo，也不需要把全部任务上传到 GitHub。

```text
ChatGPT / Codex
      ↕ 独立 MCP OAuth 授权
Cloudflare Worker /api/mcp
      ↕ 读取最新快照、条件写入
Google Drive appDataFolder/attention-planner-v2.json
      ↕ PWA 自己同步
电脑 PWA / iPhone PWA
```

PWA 和电脑可以关闭，远程服务仍能处理 Drive 上最后同步成功的内容。设备上尚未同步的修改不可见；AI 写入后，重新打开 PWA 并同步才会看到结果。AI 改日期也不会替每台关闭的 PWA 重新登记推送计划，仍应让常用设备打开并同步一次。

仓库已有的 `apps/mcp-server` 连接本地 Mindwtr SQLite 或自建 Mindwtr Cloud；它也能提供 HTTP，但并未自动接通本 PWA。这里的远程接口位于 `apps/sync-broker`，复用现有任务核心规则，连接当前 Google Drive 文件。

## 你能让 AI 做什么

| 操作 | 第一版行为 |
| --- | --- |
| 按标题查找、列出任务、读取正文与清单 | 授权后读取，不改数据 |
| 新建任务或草稿 | 直接保存为 Inbox 中的独立任务；可附正文和普通步骤 |
| 修改已有标题、正文、普通步骤 | 先显示前后差异，由你打开确认页批准 |
| 把任务放入另一任务，或移出父任务 | 保留独立任务身份；先确认，禁止形成循环 |
| 删除 | 先确认，只进回收站，不永久清除 |
| 完成、重新打开 | 先确认，并展示周期任务或时间块的连带结果 |
| 修改可开始日期、截止日期 | 先确认；不把所有日期混成旧版 `startTime` |
| 新增、移动、取消时间块 | 先确认，使用当前 planner 工作时段模型 |

父任务的完成或删除不会连带完成／删除独立子任务。重新打开任务会回到 Ready，但不会自动恢复已取消的时段，也不会删除已经生成的下一次周期任务。

没有修改项目、修改账号设置、下载附件、任意读写 Drive 文件、永久删除或读取学校 Outlook 日历的工具。

## 权限到底授予了什么

第一版连接至少需要读取权限，创建和提议权限可选：

- `tasks:read`（必需）：查询任务库并读取任务内容。
- `tasks:create`：创建新的 Inbox 任务和草稿。
- `tasks:propose`：提出对已有任务的修改；还需要 `tasks:read`，以便提供可信的前后预览。实际写入另需你在浏览器确认。

**读取权限覆盖整个可查询任务库，不是只授权某一个任务。** 每次工具调用尽量少返回字段，不等于服务端存在逐任务访问控制。如果不能接受该 AI 具备查询任务库的权限，第一版不要连接它；当前没有“只创建、不读取”的授权模式。

ChatGPT 与 Codex 分别授权、分别撤销。它们拿到的是本服务的 MCP 令牌，不是你的 Google Drive 令牌、Google 密码或浏览器 Cookie。不要把这些凭据粘贴到对话里。

## 部署前：维护者需要完成什么

1. 从 PWA 导出完整备份，让所有常用设备先完成同步。
2. 保持 `MCP_ENABLED=false`，确认已有 Google OAuth 和 `ALLOWED_EMAIL` 配置正常。仍只允许原来的个人账号，不请求新的宽泛 Drive 权限。
3. 在 Cloudflare 创建独立 KV 命名空间，将真实 ID 绑定为 `OAUTH_KV`。仓库不内置生产 ID；具体创建方式可使用 Dashboard 或当前 Wrangler 的 KV namespace 命令。
4. 保留 `MCP_WORKSPACES` 绑定及 `v2-mcp` Durable Object migration；发布时同时覆盖 `/api/*` 和 `/.well-known/oauth-*` 路由。`PUBLIC_ORIGIN` 应为 `https://todo.onthat.top`。
5. 发布包含强 ETag／`If-Match` 条件写入和同名文件保护的 PWA 更新，并让所有会写入 Drive 的设备刷新到该版本。旧客户端不能仅靠新 Worker 自动获得这些保护。
6. 发布对应隐私政策，核对 Worker secrets 和数据处理边界。不要启用正文日志、把真实任务当测试夹具或把 Google token 放进 MCP 客户端配置。
7. 在独立测试部署和隔离数据上启用 MCP，完成下述验收后，再由维护者确认生产的 `MCP_ENABLED=true` 并部署；开关关闭或缺少 `OAUTH_KV` 时，接口返回未启用。
8. 对公开的 OAuth 注册／授权端点配置边缘限流和必要的访问防护，并监测不含正文的异常请求指标。可用规则与费用依 Cloudflare 套餐而定，不假设免费额度包含全部防护。Worker 内部每个活跃 Durable Object 的每分钟 60 次限制不覆盖未授权注册，也不是抗滥用边界的替代品。

配置和服务器细节见 [sync-broker README](../apps/sync-broker/README.md)。已应用的 migration 不能通过删配置来“回滚”；停用 MCP 应改功能开关，而不是删除数据或迁移历史。

## ChatGPT 怎么连接

部署启用后，在账号支持的自定义 MCP／插件连接入口添加：

| 字段 | 值 |
| --- | --- |
| 名称 | Attention Planner |
| 远程 MCP 地址 | `https://todo.onthat.top/api/mcp` |
| 授权方式 | OAuth |

完成浏览器中的个人账号登录和权限确认，然后在对话里选择该连接。无需上传 Google Drive JSON，也无需填写 Google client secret。

ChatGPT 的入口名称、开发者模式和手机支持取决于账号、工作区及版本；不要假定网页连接成功就代表所有手机场景均已验证。以当前 [OpenAI 官方连接教程](https://developers.openai.com/plugins/build/app-quickstart) 和 [OAuth 说明](https://developers.openai.com/plugins/build/auth) 为准。本项目尚未完成真实客户端验收。

## Codex 怎么连接

部署启用后，可使用 Codex 的远程 MCP 配置入口；如果使用 CLI，可添加配置：

```toml
[mcp_servers.attention_planner]
url = "https://todo.onthat.top/api/mcp"
```

然后执行登录和查看配置：

```sh
codex mcp login attention_planner
codex mcp list
```

在打开的浏览器完成授权。不要为此配置静态 Google bearer token，也不要把密钥提交到仓库。不同 Codex 表面的配置入口与继承关系应以当前 [官方 MCP 文档](https://learn.chatgpt.com/docs/extend/mcp?surface=cli) 为准；此处提供的是服务连接参数，不是对这台客户端已成功接入的声明。

## 实际怎么用

先用无敏感信息的演示任务尝试：

> 在 Attention Planner 的 Inbox 新建“演示：复习提纲”，正文写三段提纲，不要设置日期。

> 找到“演示：复习提纲”，读取正文，提出精简版；不要直接覆盖。

> 把“演示：复习提纲”标记完成，先让我确认。

第二、三种请求只会生成待确认操作。打开 AI 返回的 `todo.onthat.top/api/mcp/proposals/…` 链接，核对任务、修改前后和警告，再选批准或拒绝。聊天里的“已建议”“已生成预览”不等于已经保存。AI 不能通过 MCP 自行点击批准。

排程时要明确日期、当地钟点和时区，例如“2026-10-01，America/Chicago，14:00，30 分钟”。确认页会提示：**只检查已同步的任务时间块，未检查 Outlook 会议或课程**。请先核对外部日历。完成周期任务时还要检查列出的下一次日期；远程核心运行在 UTC，跨夏令时的带时刻周期尤其需要核对。

## 拒绝、冲突和撤销连接

- **不喜欢草稿**：已有任务的提议可直接拒绝，不会写入；新建草稿已经在 Inbox，可在 PWA 删除，或让 AI 提出删除并由你确认。
- **预览过期**：24 小时后不能批准，让 AI 读取最新数据重新生成。
- **另一设备已经编辑**：当前保守规则下，任意任务、其容器或同步设置变化都可能使旧预览失效。不要强行覆盖，重新预览即可。
- **写入结果不确定**：可能是 Drive 已接受写入但响应丢失。使用原操作查询状态，不要换新的请求标识重新提交，防止重复任务或重复周期实例。
- **撤销一个客户端**：打开 [AI 连接管理](https://todo.onthat.top/api/mcp/connections)，登录个人账号并撤销对应连接。不要把它与“断开 Google Drive”混为一谈。
- **立即停用整个远程入口**：维护者设置 `MCP_ENABLED=false` 并重新部署。撤销使用 KV，传播有延迟；不应承诺全球瞬时生效。

访问令牌有效期配置为 15 分钟，刷新令牌为 30 天；不等于保证永久不用重新授权。撤销连接不会撤回已送入 AI 对话的文字，也不会自动回滚已批准的修改。

## 隐私与保留

普通 PWA 同步仍由浏览器直连 Drive。启用远程 MCP 后，Cloudflare Worker 为检查、合并和条件写入会在请求期间处理**整个应用同步快照**，包含任务、项目和同步设置；AI 工具不返回设置、附件或外部日历导出。

服务器不持久保存整库快照，但会 AES-GCM 加密保存操作记录，其中包括涉及任务的必要内容、前后预览、客户端身份、状态和写入结果摘要。记录七天后不可再读取，后台按小时清理；批准窗口只有 24 小时。这是应用层加密，并不意味着执行程序无法读取正文。

你实际调用的 AI 提供商会收到工具返回的内容。其对话保留、训练使用和数据控制取决于具体服务、账号及设置，本项目不能替所有提供商承诺“不留存”或“不训练”。详见 [隐私说明](./PRIVACY.md)。

## 上线验收清单

以下是待执行的发布门槛，不是已经完成的验证记录：

- 未授权请求拿不到任务内容；非白名单账号不能连接；读取为必需基线，创建／提议权限分别受限；公开 OAuth 端点的边缘限流已配置并验证。
- ChatGPT 与 Codex 分别完成 OAuth、只读查询、创建演示草稿和断开连接；手机使用单独验证。
- 对演示任务提出修改，拒绝后数据不变，批准后只改变展示的内容；其他客户端不能读取此连接的操作记录。
- 用隔离 Drive 文件验证强 ETag 的真实 `If-Match` 行为：过期版本必须失败，不覆盖另一个客户端的数据；确认同名文件冲突会停止写入。
- 模拟响应丢失、操作重试和并发编辑，不产生重复草稿、重复周期实例或静默覆盖。
- 常用 PWA 更新后能同步 AI 的修改，取消时间块不会被旧 `startTime` 恢复；iPhone 提醒需重新登记并单独测试。
- 撤销后复查读取与批准被拒绝，并检查隐私页面、日志和加密记录清理配置。

本地测试使用合成夹具与模拟 Drive，不接触真实个人任务。真实账号／设备验证应另行记录结果，不能用单元测试通过替代。
