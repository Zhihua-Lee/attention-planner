# AI 连接（MCP）

让 ChatGPT、Claude 等支持远程 MCP 的 AI 客户端读写你的清单。

## 连接

1. 在 AI 客户端里添加 MCP 服务器（“连接器”“自定义集成”之类），地址填：

   ```
   https://todo.onthat.top/api/mcp
   ```

   设置 → AI 连接里也能复制这个地址。

2. 客户端会打开一个浏览器页面。如果这个浏览器还没登录 Attention Planner，会先让你登录 Google。
3. 页面会写明是哪个 AI、权限会交给哪个网址。勾选权限后点“允许”。
   - 查看任务、日程和“现在做什么”（必选）
   - 新建任务、修改已有任务（都先发来让你批准）

### Claude Code

1. 在终端添加（`--scope user` 表示所有项目都能用）：

   ```bash
   claude mcp add --scope user --transport http attention-planner https://todo.onthat.top/api/mcp
   ```

2. 在 Claude Code 里输入 `/mcp`，选 `attention-planner` → Authenticate。浏览器会打开授权页，页面会提示“这会把权限交给你电脑上的一个程序”——这是正常的，Claude Code 在本机接收授权。点“允许”后回到 Claude Code。
3. 用 `claude mcp list` 查看状态，或直接问“现在该做什么”。
4. 不想每次确认工具调用：在设置的 `permissions.allow` 里加 `mcp__attention-planner`。

桌面版（Code 标签页）和 VS Code 扩展读的是同一份配置，加一次三处都能用。授权过期或想换账号：在 `/mcp` 里选它 → Re-authenticate 或 Clear authentication。

## AI 能做什么

| 工具                      | 作用                                                                                                                                                                                                      |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `what_now`（含目标）      | 现在该做什么、为什么，几个备选，当前和下一个日程，以及截止前时间够不够                                                                                                                                    |
| `list_tasks`              | 清单，可按今天、7 天内截止、有截止、新加的、暂缓、区域、项目或关键词筛选                                                                                                                                  |
| `get_task`                | 一个任务的全部内容（备注、步骤、安排）和在应用里打开它的链接                                                                                                                                              |
| `find_time`               | 给某个任务找空档（和应用里的“找时间”一样），预留要通过提议的“安排”                                                                                                                                        |
| `agenda`                  | 每天的日程（Outlook 和订阅的日历）、预留时段、安排和截止                                                                                                                                                  |
| `list_areas_and_projects` | 区域和项目，以及各自还有几件没做完                                                                                                                                                                        |
| `add_task`                | 记下一件新任务，等你批准（设置里可改成立即保存）。支持和输入框一样的快捷写法，比如“周五交表格 2小时 !”“每天 看邮件”；可以指定关联的任务和明确的重复规则                                                   |
| `propose_changes`         | 提议修改：改字段、完成、重新打开、暂缓、安排 / 改时间 / 取消安排（可以只为其中一个步骤）、加 / 勾 / 改 / 删步骤、步骤独立成任务、关联到别的任务、设置或停止重复、删除；以及项目改名或设“按顺序”、区域改名 |
| `get_proposal`            | 查提议的状态                                                                                                                                                                                              |
| `list_proposals`          | 还在等你批准的提议（不管哪个 AI 提的），每条写明会做什么、是不是它自己提的；也可以带上最近一个月处理过的                                                                                                  |
| `withdraw_proposal`       | 撤回自己提的、还没处理的提议，什么都不会改；别的 AI 的提议撤不了                                                                                                                                          |

## 新建和修改要你批准

AI 新建任务或提议修改已有任务时，什么都不会变。不想每次批准新任务：设置 → AI 连接 → 勾选“AI 新建任务无需批准”，新任务就立即保存（修改已有任务仍要批准）。提议和任务存在一起，同步到每台设备：

- 清单顶部出现“AI 提议 · 数量”，点开后每条提议把它涉及的任务画成清单里的样子：新任务是虚线框，要删的划掉，改动的地方高亮、旧值划掉放在旁边；“明细”里还有逐条文字。
- 被改到的任务那一行标着“AI 提议”；点开任务，详情最上面是这条提议里关于它的改动。
- 点“批准全部”，所有改动作为一次修改套用，可以撤销（撤销后提议回到待批准）；点“拒绝”，什么都不变。
- AI 给的链接（`/?proposal=…`）会直接打开清单并定位到这条提议。
- 开着提醒的设备会收到一条“AI 提议了修改”的通知，点开直接到这条提议。推送服务只经手一个编号。
- 两周没处理的提议不再显示；处理过的保留一个月。

新建的任务和批准后的改动，来源都记为 `ai`。

## 断开

设置 → AI 连接 → 管理（`/api/ai/connections`）会列出已连接的 AI，可以逐个断开。断开不会删除任何任务。

## 说明

- 日期和时间按 America/Chicago 时区计算。
- 日程只包括 Outlook 导出和设置里订阅的日历；在某台设备上导入的 .ics 文件只留在那台设备上。
- 连接借用的是你允许时那个浏览器的登录状态。登录过期后 AI 会提示重新连接：在浏览器里打开一次应用，再在 AI 客户端里重新连接即可。
