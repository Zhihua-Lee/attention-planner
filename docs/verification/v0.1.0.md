# v0.1.0 First working build

## Changes

Everything in the 0.1.0 changelog entry. The design follows [docs/design.md](../design.md).

## Automated checks

- **Unit (Vitest)**: all 38 pass. Repeat rules (weekly, every-n-weeks, month ends, until, intervals, round keys and
  opening times, after-completion rounds, copy series by count/until); task changes (stamping, reopen rounds finished by
  the last step and reopened by unchecking, new copies with shifted dates and reset steps, step order, undo by
  restore); NOW order; free time and capacity; linked-task order; capture parsing (Chinese and English); legacy import
  (fields, arrangements, snoozes, both repeat styles, links, skipped deletions); `.ics` import (weekly repeats, all-day
  skipped, escapes); sync (two devices converging, no redundant writes, retry after a concurrent write, events stay
  local); Google Drive remote against a fake API (new file, ETag conditional write, 412 mapped to a conflict).
- **Browser (Playwright, Chromium)**: 65 pass, 1 skipped, over three projects: desktop, phone (Pixel 7) and desktop
  with reduced motion. The keyboard-shortcut case is skipped on phone by design. Covered: capture parsing and chips,
  reserving a time, undo from the toast, reload persistence, completing and undoing, in-place editing of every
  property, Markdown notes, filters and areas, linked tasks, NOW reasons and cycling, reserved time now, agenda
  navigation by day and week, the capacity warning, reopen rounds across days, new copies, search, keyboard shortcuts,
  settings applying at once (language, chip order), legacy JSON import, `.ics` import, and no horizontal scroll.
- Prettier, TypeScript (`strict`, no unused code) and the third-party notices check are clean.

## Manual checks

Screenshots of NOW, the list and an expanded task at 390 px (light) and 1280 px (dark) with real typed input; no
console errors. They showed the arrangement hidden on phones, an empty timeline before 06:00, zero-value "reserved/done"
text and a duplicated title; all four were fixed before release.

## Limits

- Google Drive sync was not exercised against the real Drive or the sync broker: that needs a Google sign-in and the
  broker to accept this app's origin.
- Outlook calendar and push reminders are not built.
- Logging minutes worked inside a reserved time is not in the interface yet (the data model and import keep it).
- Only Chromium was used for browser tests; Safari on iPhone was not tested.
