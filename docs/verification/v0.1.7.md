# v0.1.7 Calendar subscriptions

## Changes

See the 0.1.7 changelog entry.

## Automated checks

- Unit: all 56 pass. New: the `/ics` function accepts https and webcal, refuses file, localhost, private addresses,
  credentials in the address and non-addresses; passes a calendar through and refuses an HTML page.
- Browser: 107 pass, 1 skipped (desktop, phone, reduced motion). New: subscribing by a webcal address shows the event
  (with its location) in the agenda and its count in Settings; unsubscribing removes it.

## Manual checks

After deploying, `/ics` on the live site fetched a public calendar and refused a non-calendar page.

## Limits

- A feed that needs a sign-in cannot be read; use its secret or public link.
