# v0.1.5 Reminders, concurrent edits, projects in order

## Changes

See the 0.1.5 changelog entry.

## Automated checks

- Unit: all 53 pass. New: reminder times (deadline day, an hour before a timed deadline, step deadlines, minutes
  before reserved times, settings, finished work and past or far-off times left out, ids the push service accepts and
  that map back to their task); two devices editing a note concurrently both keep the other version, resolving on one
  clears it on both; edits one after another are not flagged; a project in order suggests only its first unfinished
  task and moves on when it is done.
- Browser: 98 pass, 1 skipped (desktop, phone, reduced motion). New: a seeded concurrent edit shows the notice, the
  comparison and "use the other"; reminder times persist in Settings; a project in order shows "排队中" and NOW suggests
  its first task.
- The built service worker imports `push-sw.js`.

## Limits

- Real push delivery was not exercised here: it needs notification permission and a subscription on a real device. On
  iPhone it works only from the Home Screen app (iOS 16.4+).
- Tasks in a project done in order follow the order they were added; there is no manual reordering yet.
