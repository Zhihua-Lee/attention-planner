# v0.1.1 Replaces the previous app

## Changes

The domain todo.onthat.top now points at this app. On first start it imports the previous app's data from the same
browser (once, keeping record ids so devices merge), connects sync when the broker already has Google Drive connected,
and reads the Outlook calendar export from Google Drive after each sync. Security headers were added.

## Automated checks

- Unit: all 41 pass. New: the Outlook export reader (array, `events` and Graph `value` shapes; all-day skipped;
  midnight crossings split per day; window; Graph `{ dateTime }`), finding the export file by its marker, broker tokens.
- Browser: 68 pass, 1 skipped (desktop, phone, reduced motion). New: the previous app's data is imported once with a
  toast and survives a reload without a second import.

## Manual checks

- todo.onthat.top serves this app (title, Workbox service worker at `/sw.js` replacing the previous app's), and
  `/api` still reaches the sync broker.
- The deployed site loads with the new security headers and no console errors; a task survives a reload.

## Limits

- The import, the automatic sync connection and the Outlook calendar were not observed in the owner's own browser from
  here; they need the owner's signed-in session.
- Push reminders are not built.
