- Unit: all 78 pass. New:
  - a weekly task that reopens, due the day after it opens, with a step due on the day and a reserved time: the
    next round sees all three a week later, and NOW calls the step "due today" instead of "overdue by 7 days";
    changing the deadline or adding a plan in that round stores it relative to the first round;
  - a new copy carries a step's deadline (moved a week) and estimate;
  - a snoozed task due today is back in NOW while a snoozed task due later is not; the "today" filter agrees;
  - in a project done in order, a weekly task neither waits nor holds back the first one-off task, and the second
    one-off task still waits.
- Browser: 129 pass, 3 skipped on phone (the keyboard tests). New: Ctrl+S is kept from the browser and shows
  "已自动保存"; Ctrl+F opens the task search.
