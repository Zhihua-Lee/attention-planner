# 元素之间的互动

一个任务由这些部分组成：截止（含时刻）、安排（某天 / 某段 / 预留时间）、用时、★ 重要、暂缓、步骤（各自可有截止、用时、重复）、重复（原地重开 / 新建一份）、区域、上级任务。这份文档列出它们两两之间现在怎样互相影响，哪些已经闭环，哪些还没有。

“闭环”指：任何组合下，系统算出来的东西（NOW 的推荐、逾期、时间够不够、提醒、清单筛选）都和直觉一致，而且不会留下需要手动收拾的残留状态。

## 已经闭环的

| 组合                              | 现在的行为                                                                                                                                                                                                                                                    |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 截止 × 步骤截止                   | “有效截止”取任务截止和未完成步骤截止中最早的；NOW、清单、提醒、“今天”筛选、时间够不够都用它。步骤勾掉后它的截止不再算。                                                                                                                                       |
| 用时 × 步骤用时                   | 任务没填总用时时，用时 = 步骤用时之和；“还剩”只算没勾的步骤。填了总用时则以总用时为准，减去预留时段里记下的已做时间。                                                                                                                                         |
| 用时 × 安排                       | 半耦合、单向：用时决定“找时间”建议的长度（还差 = 用时 − 已排，没填按 1 小时，每段最多 2 小时）；预留多少都不会改用时。日历空白处的推荐也按“还差”判断放不放得下（0.2.7 起）。                                                                                  |
| 截止 × 用时                       | “时间够不够”：按截止排序，把每个截止前要做的用时加起来，和截止前工作时间里的空闲比较（日历占用和预留都扣掉）。                                                                                                                                                |
| 新建一份 × 截止 / 安排 / 步骤     | 完成时生成下一份，截止、所有安排和步骤的截止按同一个间隔顺延，步骤的用时一起带走，步骤重新变成没勾（0.2.6 起带走步骤的截止和用时）。次数、结束日期用完就不再生成。                                                                                            |
| 原地重开 × 截止 / 步骤截止 / 安排 | 这些日期按第一轮写下，每一轮看到的是“本轮那天 + 同样的间隔”：第一轮周二截止周三，下一轮就是下周二截止下周三；预留的时间每轮都在。跳过的轮次不留下旧日期。在后面的轮次里改日期，按同样的间隔换算回第一轮保存，所以每轮都看到改后的结果（0.2.6 起）。           |
| 原地重开 × 步骤                   | 跟随任务的步骤每轮清空；“不重复”的步骤勾一次永久有效；单独重复的步骤按自己的轮次。设置里开了“步骤都勾完时 · 自动完成任务”，所有步骤都完成时这一轮自动完成；默认不开，要自己点圆圈。点圆圈完成本轮会勾掉跟随任务的步骤。取消勾选一步会重新打开已完成的这一轮。 |
| 暂缓 × NOW / 筛选                 | 暂缓到期前不进 NOW、不算“今天”；清单里排在后面、变灰。                                                                                                                                                                                                        |
| 暂缓 × 截止                       | 截止（包括步骤截止）在暂缓期内到了当天或已经逾期，任务就回到 NOW 和“今天”，不再被暂缓挡住（0.2.6 起）。                                                                                                                                                       |
| 区域 × 上级任务                   | 子任务没设区域时，算在上级任务（一路往上找）的区域里：区域筛选里有它，详情显示“随上级任务”。                                                                                                                                                                  |
| 按区域分组 × 清单                 | 只在“全部”里：按区域分段、没有区域的最后，段内保持原排序；段可以折叠（每台设备各自记住）；手动排序时只能在段内拖动。只影响显示。                                                                                                                              |
| 只看下一个 × 清单                 | 每个上级任务下只显示按当前排序最前、没做完的一个子任务，其余收起并在上级那行计数；只影响清单显示，NOW 和提醒照旧。                                                                                                                                            |
| 历史 × 所有改动                   | 每次改动保存时，比较改动前后的任务，把勾选、完成、重开、截止、安排、已做时间、暂缓记进任务的历史，附上当时的安排和截止；新建和删除任务不记。完成一轮时勾掉的步骤只记一条“完成”。撤销会作废它撤回的那几条；同步按条合并，作废也会传到其他设备。                |
| 本地路径 × 设备                   | 正文里的完整路径（D:\…，有空格的放在反引号里）显示成 `ap-open:` 链接。这台设备没勾“点路径直接打开”时，点击只复制路径；勾了就交给浏览器，由 open-link 小程序打开，它只开允许文件夹里的文件夹和 .md、.txt、.pdf、图片。每台设备各自设置。                       |
| 删除区域                          | 属于它的任务自动变成未分类。                                                                                                                                                                                                                                  |
| 快捷写法 × 重复                   | “每周五交周报”：截止下一个周五、规则从那天开始、每次新建一份；“每天 看邮件”：原地重开。                                                                                                                                                                       |
| 已完成 × 单独重复的步骤           | 任务（或原地重开的这一轮）完成之后，按自己节奏重复的步骤又到时间，任务就回到清单，像没完成一样参与 NOW、今天和提醒；勾掉这一步，它又算完成。新建一份的任务不会：下一份里有这一步。                                                                            |
| 非重复任务 × 步骤                 | 默认勾完所有步骤不会自动完成任务，要自己点圆圈：做完步骤后常常还有收尾。想自动完成，在设置 → 步骤都勾完时里打开（对所有任务都一样，原地重开的是完成本轮）。在已完成的任务里取消勾选一步，任务回到未完成（新建一份的除外，它的下一份已经生成）。               |
