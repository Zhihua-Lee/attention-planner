# 元素之间的互动

一个任务由这些部分组成：截止（含时刻）、安排（某天 / 某段 / 预留时间）、用时、★ 重要、暂缓、步骤（各自可有截止、用时、重复）、重复（原地重开 / 新建一份）、归属（区域、项目）、关联。这份文档列出它们两两之间现在怎样互相影响，哪些已经闭环，哪些还没有。

“闭环”指：任何组合下，系统算出来的东西（NOW 的推荐、逾期、时间够不够、提醒、清单筛选）都和直觉一致，而且不会留下需要手动收拾的残留状态。

## 已经闭环的

| 组合                   | 现在的行为                                                                                                                                                           |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 截止 × 步骤截止        | “有效截止”取任务截止和未完成步骤截止中最早的；NOW、清单、提醒、“今天”筛选、时间够不够都用它。步骤勾掉后它的截止不再算。                                              |
| 用时 × 步骤用时        | 任务没填总用时时，用时 = 步骤用时之和；“还剩”只算没勾的步骤。填了总用时则以总用时为准，减去预留时段里记下的已做时间。                                                |
| 截止 × 用时            | “时间够不够”：按截止排序，把每个截止前要做的用时加起来，和截止前工作时间里的空闲比较（日历占用和预留都扣掉）。                                                       |
| 新建一份 × 截止 / 安排 | 完成时生成下一份，截止和所有安排按同一个间隔顺延；次数、结束日期用完就不再生成。                                                                                     |
| 原地重开 × 步骤        | 跟随任务的步骤每轮清空；“不重复”的步骤勾一次永久有效；单独重复的步骤按自己的轮次。所有步骤都完成，这一轮才自动完成（0.2.4 起）。点圆圈完成本轮会勾掉跟随任务的步骤。 |
| 暂缓 × NOW / 筛选      | 暂缓到期前不进 NOW、不算“今天”；清单里排在后面、变灰。                                                                                                               |
| 项目“按顺序” × NOW     | 只有项目里最早添加、还没做完的任务进 NOW，其余显示“排队中”。                                                                                                         |
| 删除区域 / 项目        | 属于它的任务自动变成未分类。                                                                                                                                         |
| 快捷写法 × 重复        | “每周五交周报”：截止下一个周五、规则从那天开始、每次新建一份；“每天 看邮件”：原地重开。                                                                              |

## 还没闭环的

| 组合                | 问题                                                                                         | 例子                                                  |
| ------------------- | -------------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| 原地重开 × 截止     | 截止是固定日期，不跟着轮次走。第一轮之后就一直“逾期”，天数越来越大；提醒只在第一次的日期响。 | 每周二的 TA 清单设了截止 9/29，10/6 显示“逾期 7 天”。 |
| 原地重开 × 步骤截止 | 同上：跟随任务的步骤每轮清空，但它的截止停在第一轮。                                         |                                                       |
| 原地重开 × 安排     | 安排是固定日期，不会每轮出现。                                                               | 每周二 14:00 预留的时间，只在第一个周二有。           |
| 新建一份 × 步骤     | 下一份只带走步骤的文字、顺序和重复；步骤的截止和用时丢了，于是下一份的用时、有效截止都不对。 |                                                       |
| 暂缓 × 截止         | 暂缓的任务即使截止快到或已经逾期，也不进 NOW；只在“时间够不够”里还算着它。                   | 暂缓到下周、但后天截止。                              |
| 按顺序的项目 × 重复 | 原地重开的任务每轮重新打开后又排回队首，后面的任务会被它反复挡住。                           |                                                       |
| 非重复任务 × 步骤   | 勾完所有步骤不会自动完成任务（原地重开的会）。两种任务行为不一致，是有意还是该统一，还没定。 |                                                       |

## 建议的收口方式

1. **原地重开：日期按“这一轮”来算。** 截止、步骤截止和安排都存成“相对本轮那天”的偏移，比如“本轮那天 + 2 天”“本轮那天 14:00”，显示和计算时换算成具体日期。只存一份，不用每轮改数据，也就不会在同步时互相覆盖。
2. **新建一份：步骤的截止和用时一起带走**，截止和任务截止按同一个间隔顺延。
3. **暂缓不挡截止**：截止在暂缓期内到来时，到截止前一天（或当天）自动回到 NOW，并标“暂缓中，但快截止了”。
4. **按顺序的项目里，重复任务不参与排队**，它们各自按轮次出现。
5. **勾完所有步骤**：非重复任务也自动完成，和原地重开一致；完成后可以撤销。这一条要你决定。
